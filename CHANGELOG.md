# Changelog

## [0.1.0] - 2026-11-24
- Initial version: Tween engine (move, scale, rotate, punch, shake, float/vector/color, delay, 12 eases,
  loops/yoyo, unscaled time), trauma-based CameraShaker that never drifts, TimeEffects (hit stop, slow
  motion, safe with pause menus), HitFlash via MaterialPropertyBlock, pooled FloatingText,
  FeedbackPlayer with 11 effect types, accessibility switches.
- Editor: Feedback Player inspector (add/reorder/remove, play button), demo scene, add camera shaker.
- 16 PlayMode tests.
